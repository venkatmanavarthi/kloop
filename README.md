# KrackLoop Interview

KrackLoop Interview is a free, open-source app that helps you prepare for job interviews in any field.

Whether you are a nurse, teacher, accountant, salesperson or software engineer, KrackLoop gives you practice questions that match the job you are applying for.

## Contributing

Everyone is welcome to help. You don't need to be a programmer. You can:

- Share ideas or suggest features by opening an issue.
- Tell us what interviews are like in your field.
- Help write and review practice questions.
- Help build the app once development starts.
